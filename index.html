🔌 연결·사용 가이드

우리 반 확장보드 sensor:bit(Elecfreaks)에 센서를 연결하는 방법과, 코딩할 때 꼭 알아야 할 팁이에요. 확장보드 실물 사진 보기 ↗

① 선 연결: G · V · S 색 맞추기

확장보드의 핀은 번호(1~16)마다 세로로 3개씩 있어요. 위에서부터 노랑 = S(신호), 빨강 = V(전원), 검정 = G(GND)예요. 센서 선의 색을 핀 색과 맞춰 꽂아요.

G (GND, −) · 검정/갈색 선 V (전원, +3V) · 빨강 선 S (신호) · 노랑/흰색/주황 선

⚠ G와 V를 거꾸로 꽂으면 센서가 고장날 수 있어요. 선을 꽂거나 뺄 때는 전원(USB·배터리)을 먼저 빼요.

아날로그 값(0~1023)을 읽는 센서 서보·초음파·디지털 센서 허스키렌즈 전용 피하기
  • P0: 핀 줄(1~16)에 없어요. 확장보드의 부저(소리)와 이어폰 단자에 연결되어 있어요.
  • P3·P4·P6·P7·P9·P10: LED 화면과 함께 쓰는 핀이에요. 꽂으면 화면이 이상해지니 피해요.
  • P5·P11: 버튼 A·B와 같은 핀이에요.
  • 초음파(4핀): VCC → V, GND → G는 아무 핀 줄에, Trig → P13의 S, Echo → P14의 S에 점퍼선으로 꽂아요.
  • 허스키렌즈: 오른쪽 아래 G·V·CL·DA 핀에 − → G, + → V, R → CL, T → DA로 연결해요. (왼쪽 아래 검정 4구멍은 OLED 화면 전용이에요.)

③ 센서별 연결 한눈에 보기

사진의 선 이름과 아래 표를 비교하며 꽂아요. 사진을 누르면 센서 백과사전 카드가 열려요.

④ 전원

  • sensor:bit에는 따로 전원 스위치나 배터리 단자가 없어요. 마이크로비트에서 전기를 받아요.
  • 컴퓨터 USB로 연결하거나, 배터리팩을 마이크로비트 위쪽의 하얀 배터리 단자에 꽂아요.
  • 센서에는 3V가 공급돼요. 서보는 힘이 약할 수 있고, 5V 전용 센서는 잘 동작하지 않을 수 있어요.
  • 서보와 허스키렌즈를 함께 쓸 때 멈추거나 재시작되면 전기가 모자란 거예요. USB 연결이나 새 건전지를 써요.

⑤ 값 확인하기 → 기준값 정하기

"값이 300보다 작으면" 같은 기준값은 센서와 교실 환경마다 달라요. 먼저 실제 값을 보고 정해요.

  1. 센서 백과사전에서 센서를 누르고 🔎 먼저 값 확인하기 블록을 따라 만들어요.
  2. 기기 연결 후 다운로드하면 LED 화면에 숫자가 나와요.
  3. 시뮬레이터 아래 데이터 보기 장치 버튼을 누르면 값이 그래프로 보여요.
  4. 상황을 바꿔 가며 값을 기록하고, 그 중간쯤을 기준값으로 정해요.
평소 상황의 값반응해야 할 상황의 값정한 기준값
예: 620 (밝을 때)예: 140 (손으로 가렸을 때)예: 380 → "380보다 작으면"

⑥ 시뮬레이터로 먼저 시험하기

  • MakeCode 왼쪽의 시뮬레이터는 코드를 바꿀 때마다 바로 실행돼요. 기기 없이 먼저 확인해요.
  • 밝기·온도·소리 블록을 쓰면 시뮬레이터에 조절 막대가 생겨요. 끌어서 값을 바꿔 봐요.
  • 흔들기(SHAKE) 버튼, A·B 버튼, 로고도 마우스로 누를 수 있어요.
  • 아날로그 읽기를 쓰면 시뮬레이터의 핀을 눌러 값을 바꿀 수 있어요.
  • 초음파·허스키렌즈는 시뮬레이터에서 동작하지 않아요. 실제 기기로 확인해요.

⑦ 부품 안전·정리 수칙

  • 선을 꽂거나 뺄 때는 전원을 먼저 빼요.
  • 서보 팔을 손으로 억지로 돌리지 않아요.
  • 보드를 가위·클립 같은 금속 위에 두지 않아요. (합선 위험)
  • 허스키렌즈의 렌즈를 손으로 만지지 않아요.
  • 수업이 끝나면 배터리를 빼고, 부품 개수를 확인해 상자에 넣어요.
